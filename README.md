# نظام إدارة المطعم المتكامل (Mini-ERP)

يعتبر هذا التطبيق حلاً تقنياً شاملاً مصمماً خصيصاً لتلبية احتياجات المطاعم التي تدير فروعاً متعددة داخل المملكة العربية السعودية. يجمع النظام بين كفاءة الإدارة التشغيلية ودقة المحاسبة المالية وفقاً للمعايير السعودية، مما يضمن سلاسة العمل والامتثال الضريبي التام.

### المميزات الأساسية للنظام

يوفر النظام مجموعة واسعة من الأدوات الإدارية والمحاسبية التي تغطي كافة جوانب العمل اليومي، وفيما يلي تفصيل لأبرز هذه الميزات:

| الوحدة | الوصف |
| :--- | :--- |
| **الموارد البشرية** | إدارة بيانات الموظفين لكل فرع (الإقامة، الجواز، تصريح العمل، كرت العمل بأرقامها وتواريخ انتهائها)، تسجيل الحضور والغياب مع خصم تلقائي لليومية من الراتب الشهري، سلف وخصومات ومكافآت لكل عامل، وترحيل الرواتب الشهرية إلى دفتر اليومية. |
| **التنبيهات** | تنبيه عند فتح البرنامج وفي لوحة التحكم لأي وثيقة (إقامة/جواز/تصريح عمل/كرت عمل) تقترب من الانتهاء، بحد زمني قابل للتغيير (7 إلى 90 يوماً). |
| **المحاسبة والضرائب** | قيد مزدوج تلقائي لكل عملية وحساب ضريبة القيمة المضافة (15%) تلقائياً. |
| **المبيعات اليومية** | شاشة تسجيل مبيعات مبسطة: تُدخل إجمالي التحصيل اليومي شامل الضريبة لكل طريقة دفع (كاش / شبكة مدى-فيزا / تحويل بنكي) لكل فرع، ويقوم النظام تلقائياً بفصل الضريبة وترحيل القيد المحاسبي - بدون تسجيل كل طلب أو صنف على حدة. |
| **المشتريات** | فواتير مشتريات مصنّفة (مواد خام / مصروفات مرتبطة بالمشتريات / مصروفات تشغيلية) نقداً أو آجلاً، مع مرتجعات مشتريات. |
| **الموردون** | إضافة عدة موردين مع رصيد افتتاحي، تسجيل السداد لكل مورد، وكشف حساب مفصل يوضح الرصيد الدائن الحالي لكل مورد على حدة. |
| **التقارير الجاهزة** | تقرير يومي / أسبوعي / شهري / سنوي / فترة مخصصة، لكل فرع أو لكل الفروع، يعرض المبيعات حسب طريقة الدفع، المشتريات والمصروفات، مجمل وصافي الربح، صافي الضريبة، وتفصيل يومي — مع إمكانية **الطباعة أو الحفظ PDF**. |
| **التقارير المالية** | ميزان مراجعة (مدين = دائن)، قائمة الدخل، حساب المتاجرة (رصيد أول المدة + المشتريات + مصروفات المشتريات - المرتجعات = تكلفة البضاعة المتاحة للبيع)، قائمة المركز المالي (أصول = التزامات + حقوق ملكية)، ولوحة تحكم تعرض صافي الربح والضريبة اليومية. |

### متطلبات التشغيل والبدء السريع

لضمان عمل التطبيق بكفاءة عالية، يجب التأكد من توفر بيئة برمجية تدعم لغة Python 3 ومكتبة PyQt6 للواجهات الرسومية. يمكن البدء بتشغيل النظام عبر الخطوات التالية:

1. تثبيت المكتبات اللازمة باستخدام الأمر: `pip install PyQt6`.
2. تشغيل الملف الرئيسي للتطبيق: `python main.py`.

> **ملاحظة:** يعتمد النظام على قاعدة بيانات SQLite محلية، مما يجعله سريعاً ومستقلاً ولا يتطلب إعدادات خادم معقدة للتشغيل الأولي.

### اختبارات التحقق

يوجد ملف اختبارات شامل يتحقق من صحة الحسابات المحاسبية وسلامة الواجهة (توازن ميزان المراجعة، توازن كل قيد على حدة، صحة احتساب الضريبة، ظهور كل الأزرار، وعدم اختفاء أي محتوى أسفل الشاشة):

```bash
QT_QPA_PLATFORM=offscreen python tests/test_app.py
```

### الهيكل التنظيمي للمشروع

تم تقسيم المشروع إلى وحدات برمجية منظمة لتسهيل عملية التطوير والصيانة المستقبليّة:

- **الواجهات (ui/):** تضم كافة النوافذ والوحدات الرسومية التفاعلية.
- **المنطق البرمجي (logic/):** يحتوي على خوارزميات المحسابية وحسابات الضرائب والرواتب.
- **قاعدة البيانات (database/):** تشمل هيكل الجداول (Schema) وعمليات الربط والبيانات التأسيسية.
