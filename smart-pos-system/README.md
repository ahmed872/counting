# Smart POS

نظام نقطة بيع (POS) لسطح المكتب، مبني بتصميم أصلي خاص بيك (مش نسخة من أي نظام تاني).

## المميزات
- شاشة كاشير: إضافة منتجات للفاتورة، خصم، ضريبة، طرق دفع.
- إدارة منتجات وفئات (كل فئة ممكن تتحدد كـ "فئة مطبخ" فتظهر أوردراتها في شاشة المطبخ).
- شاشة مطبخ منفصلة (نافذة ثانية) بتتحدث تلقائيًا كل 4 ثواني.
- سجل مبيعات.
- إعدادات عامة (اسم المتجر، العملة، نسبة الضريبة).
- قاعدة بيانات SQLite مدمجة جوه التطبيق نفسه — **مفيش أي حاجة تانية اليوزر محتاج يثبتها** (لا MySQL ولا أي سيرفر منفصل).

## التشغيل في وضع التطوير
```
cd smart-pos-system
npm install
npm start
```

## بناء ملف تثبيت Windows (exe) محليًا
```
npm run dist
```
الناتج هيكون في `dist/` (ملف Setup.exe جاهز للتوزيع).

## التوزيع التلقائي عبر GitHub (الطريقة الموصى بيها)
المشروع فيه GitHub Action جاهز (`.github/workflows/build-release.yml`) بيعمل الآتي تلقائيًا:
1. تعمل تاج (tag) بالشكل `pos-v1.0.0` وتعمله push.
2. GitHub Actions هيشغل بناء كامل على Windows، وينتج ملف exe.
3. الملف هيترفع تلقائيًا كـ **GitHub Release** مرفق بيه.
4. تاخد لينك الـ Release وتبعته لليوزر — يفتح الملف ويثبته على طول، من غير ما ينزل أي حاجة تانية.

مثال لعمل ريليز جديد:
```
git tag pos-v1.0.0
git push origin pos-v1.0.0
```

## هيكل المشروع
```
smart-pos-system/
  electron/
    main.js       # العملية الرئيسية - بتفتح النوافذ وتربط قاعدة البيانات
    preload.js    # جسر آمن بين الواجهة وقاعدة البيانات
    db.js         # كل منطق قاعدة البيانات (SQLite)
  renderer/
    index.html    # الشاشة الرئيسية (كاشير + منتجات + مبيعات + إعدادات)
    kitchen.html  # شاشة المطبخ
    app.js / kitchen.js / styles.css
```

## ملاحظة مهمة
الفولدر ده حاليًا موجود جوه ريبو تاني (`counting`) على فرع منفصل (`pos-system`) عشان مالوش تأثير على أي مشروع موجود قبل كده. لما تجهز، تقدر:
1. تنشئ ريبو فاضي جديد على GitHub باسمك المفضل.
2. تنقل محتوى فولدر `smart-pos-system/` بالكامل للريبو الجديد.
3. تبعتلي لينك الريبو الجديد وأكمل معاك من هناك مباشرة.
